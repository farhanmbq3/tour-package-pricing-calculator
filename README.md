# Tour Package Pricing Calculator

A simple pricing and margin calculator for tour operators, travel agencies, and trip planners.

This project helps small travel businesses calculate tour package prices based on costs, number of guests, desired margin, and expected profit.

## Why this exists

Many small tour operators still calculate package prices manually using notes, WhatsApp, or spreadsheets. This tool is designed to make pricing clearer, faster, and easier to repeat.

## Planned Features

- Calculate total trip cost
- Calculate cost per person
- Add transport cost
- Add hotel or accommodation cost
- Add guide fee
- Add meals and activity cost
- Add custom miscellaneous cost
- Set desired profit margin
- Show final selling price per person
- Show estimated total profit
- Support multiple currencies

## Example Use Cases

- Lombok tour packages
- Bali private trips
- Surf trips
- Hiking trips
- Multi-day travel packages
- Small travel agency pricing
